### VAIRC-Related Technical Development Series on Jetson Nano
This series of topics focuses on introducing the development techniques related to VAIRC (Vehicle AI Research and Computing, a hypothetical term representing AI-driven research and computing applications for vehicles or similar domains) using the NVIDIA Jetson Nano platform.

#### Topic 1: "Inference of Pre-trained Models on Jetson Nano"
This topic explores the process of training a model for MNIST handwritten digit recognition on an external computing device, converting it, and then importing it onto the Jetson Nano for recognition and inference. It demonstrates how to leverage pre-existing models for edge computing applications on the Jetson Nano.
#### Topic 2: "Vision Recognition with Jetson Nano"
This segment delves into programming on the Jetson Nano platform to perform inference with pre-trained models. It aims to acquaint beginners with the JupyterLab programming environment and the JetPack SDK on the Jetson Nano, laying a solid foundation for VAIRC-related Python programming on the device. Through hands-on examples, learners will grasp the essentials of vision recognition using Jetson Nano.

#### Topic 3: "Jetson Nano and Darknet"
This topic introduces the installation of the Darknet neural network development framework on the Jetson Nano platform. It guides beginners through the process of downloading Darknet's source code, setting up its compilation environment, and using C compilation on the Jetson Nano to install and configure the Darknet development platform. The objective is to empower users with the skills necessary to leverage Darknet for AI-driven projects on the Jetson Nano.
By following this series, developers and enthusiasts can gain a comprehensive understanding of how to harness the power of the Jetson Nano for VAIRC-related tasks, from model inference to advanced vision recognition and neural network development using Darknet.

### VAIRC相关的Jetson nano的技术开发专题
本专题系列为介绍与VAIRC相关的Jetson nano的开发技术。

专题1“预训练模型在Jetson nano上推理”
介绍在外部计算设备上训练一个MNIST手写数字的识别模型，经变换后导入到Jetson进行识别推理。

专题2“Jetson视觉识别”
介绍在Jetson Nano平台上导入预训练模型进行推理的编程，让初学者能够熟悉Jetson Nano上Jupyterlab编程和JetPACK环境，建立VAIRC程序Jetson端python编程的基础。

专题3“Jetson与Darknet”
介绍在Jetson Nano平台上安装Darknet神经网络开发框架，让初学者学习如何下载Darknet源码、设置其编译环境及使用Jetson Nano上的C编译、安装Jetson nano上运行的Darknet开发平台。
